# 开发与验证说明

当前代码处于 v0.5.0-dev 开发阶段，不能用于生产 VPS。默认菜单可做只读查询；系统修改代码仅在显式传入 `--experimental`（或菜单内输入 `ENABLE`）时可选用，并且还要求 Ubuntu / Debian、root、交互式终端及逐次确认。演示模式始终不运行操作。

## 软件管理试验范围

- 可选：更新现有 APT 软件源索引、升级已安装的软件包、安装预设的基础 / 网络 / 查看 / 安全工具。
- 不修改软件源配置，不执行 `full-upgrade`、`autoremove` 或包卸载；安装和升级通过 `--no-remove` 在需要删除软件包时中止。
- 升级和安装先执行 APT 的模拟模式，模拟不持锁，实际执行时系统状态可能已变化。APT 或已有配置的钩子可能产生额外影响；用户取消时不执行正式修改。
- 网络目标取决于现有软件源、APT 配置、代理和重定向。界面只显示默认源文件中可识别的 HTTP(S) 主机，省略 URL 凭据和路径；它不能证明显示了所有目的地。
- 不继承 `APT_CONFIG`，避免调用者改变 APT 的配置目录、钩子和来源；代理变量会保留但不显示。
- 软件包升级无法保证回滚。APT 退出码为 0 不证明所有源都已成功刷新、所有服务正常或不需要重启。

## 其他试验功能的边界

- **3x-ui：**固定官方版本和安装脚本摘要，现有安装会被拒绝覆盖。上游脚本会执行 root 操作并查询公网 IP；证书等可选步骤有额外网络与信任边界，见 [接入记录](3X-UI-AUDIT.md)。只读取面板端口/路径，不读取账户、密码或数据库。
- **BBR / fq：**仅写入项目专属 sysctl 文件，记录原值，发现冲突或外部修改时停止。内核尚未列出 `bbr` 时会先说明并在用户确认后尝试加载 `tcp_bbr`，需要时写入 `/etc/modules-load.d/vps-script-bbr.conf`；模块不会自动卸载。重启后的生效情况未验证。
- **SSH：**只处理标准 `sshd_config.d` 布局，遇到 `Match`、其他 Include、已有多因素认证或不可判断的设置会停止。新增端口先保留旧端口；可在修改前请求 UFW 放行新端口；只有旧端口由本项目管理、当前连接使用其他端口时才能尝试关闭。仅公钥认证会影响所有账户，菜单会列出可登录账户并要求输入 `ALL USERS`；当前只验证执行账户的公钥，其他账户需自行确认。
- **UFW：**首次启用前要求默认入站策略为 `deny`，并为当前 SSH 端口添加允许规则；遇到其他防火墙服务、现有 nftables 规则或挂钩链、无法识别的 nftables 对象时停止。超时后会尝试恢复到此前未启用状态，但预先加入的允许规则会保留；如果启用过程中断而状态快照未完成、规则被其他工具修改或恢复命令失败，自动恢复可能不执行或失败。
- **Fail2ban：**为 SSH 创建项目专属 jail，已有系统 `sshd` jail 不被覆盖；UFW 已启用时优先使用 `ufw` 封禁动作。SSH 端口变化后只更新项目 jail 的 `port` 行；实际日志匹配、封禁和解封需单独测试。
- **Hy2：**只管理项目专属 nftables 表和 systemd 单元；发现已有 NAT 规则、旧版 NAT 表或 UDP 监听冲突时停止。可选在 UFW 已启用时放行 UDP 范围和目标端口；不会修改云防火墙或客户端。应用失败时会尝试清理项目文件/规则，无法确认时保留状态供人工恢复。
- **内核网络调优：**只写 `/etc/sysctl.d/91-vps-script-tuning.conf` 和项目状态文件；不改 BBR/default_qdisc、不换内核、不做 qdisc/HTB 整形、不改 initcwnd/DNS/转发/RPS/MSS。保守/代理/缓冲三档；缓冲档按内存和用户输入的预期带宽/RTT 估算，不是实测。其他 sysctl 文件设置不同值时会停止；应用失败按快照回滚，外部修改后拒绝恢复。参数改变不代表性能一定提升。
- **测试与体检：**内置机器/网络/线路/带宽测试只运行固定命令；带宽测试使用 Cloudflare 单线程下载并明确消耗流量。外部 NQ/TQ/IPQuality/NetQuality/YABS 不在本项目源码内，按各自许可证运行；固定 URL 白名单、下载到临时文件、显示 SHA 和前 120 行、需要修改模式和 `RUN` 确认。上游脚本/rootfs/二进制未固定摘要，可能安装软件、访问大量第三方节点并上传 IP/结果；只在测试 VPS 使用。
- **swap / 时区：**swap 只管理 `/swapfile-vps-script` 和带标记的 fstab 行，已有其他 swap 时停止；时区只调用 `timedatectl set-timezone`，不会修改 NTP/时钟。DNS 仅只读展示。

例如，在已准备好控制台恢复、快照和测试网络的**可丢弃测试机器**上，开发者可以启动试验模式：

```bash
./vps-admin --experimental
```

该命令本身打开菜单；选择实际操作并确认后才会运行。不要在重要 VPS 上测试。

## 本地测试

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```

测试中的 APT、SSH、防火墙、Hy2 和 swap 调用使用模拟对象，不运行真实的系统软件修改，不访问软件源。启动脚本和演示模式可以在 macOS 上验证；实际只读检测和试验功能需在 Linux 上另行验证。

## 自动检查

GitHub Actions 在 Ubuntu 虚拟机及 Debian 容器中运行单元测试与只读系统查询，结果以对应提交的运行记录为准。这些测试以模拟为主；Debian 容器不能证明 systemd、SSH、防火墙、重启持久化或跨网络协议可用。高风险功能需要带有控制台访问的独立虚拟机和 VPS 端到端测试。
